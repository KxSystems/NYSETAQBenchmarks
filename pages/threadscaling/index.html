NYSE TAQ Benchmark — Thread Scaling

Methodology and motivation Reproduce and validate results Compare query engines Hardware comparison

Results show how one solution's query (and data load) performance scales with the number of threads it is given. Instead of comparing solutions at a fixed thread count, every thread count of the selected solution is put side by side on one machine. Data resides in memory, so scaling here reflects how well the engine parallelises over CPU cores and memory bandwidth. Filters update the summary charts and detailed comparison below.
